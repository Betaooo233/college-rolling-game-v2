# 大学生人格进化论

纯前端 H5 小游戏，直接打开 `index.html` 即可运行，无需安装依赖、无需构建工具。

## 目录结构

```text
.
├── index.html          # 页面入口，按顺序加载样式、配置和主逻辑
├── styles.css          # 414 x 828 竖屏布局、信箱适配、界面动效、Flag/校园墙/报告界面
├── config.js           # 数值、卡牌、变体、Flag、事件、剧情、结局、文案、资源路径配置
├── game.js             # 资源加载、输入封装、游戏流程、剧情收集、校园墙和报告逻辑
├── assets/
│   ├── images/         # 背景、行为卡图标、人格头像、剧情场景、人物立绘和彩蛋插图
│   └── audio/          # 选择、事件、习惯、剧情揭示、结算和背景音乐
└── docs/
    ├── grd.md          # 游戏需求文档
    ├── CHANGELOG.md    # 需求与实现变更记录
    └── game_info.json  # 游戏基础信息
```

## 技术决策

- 使用原生 HTML、CSS、JavaScript 和 Canvas 2D，不依赖 Phaser、Pixi、jQuery、Webpack、Vite 或 NPM。
- 以 `414 x 828` 为核心安全布局，移动端会按视口比例动态扩展画布并居中关键 UI，尽量满屏显示且不拉伸、不裁切内容；PC 仍居中等比显示。
- 所有可调数值、卡牌效果、随机变体、Flag 目标、校园墙文案、人物熟悉度、事件选项、剧情触发、人格判定、资源路径集中在 `config.js`，方便后续调参。
- 图片和音频统一预加载；单个资源加载失败时继续进入游戏，图片自动使用几何兜底图标。
- 图鉴、校园纪事、隐藏称号、暂停存档和静音状态使用 localStorage 保存；重新开始不清空人格图鉴或校园纪事。

## 数据流向

```text
资源预加载 -> 开始页 -> 新手引导 -> 本学期 Flag 选择
  -> 16 周行为选择循环 / 行为卡随机变体
  -> 行为结算 / 校园墙吐槽 / 校园旁白或剧情演绎 / 人物熟悉度
  -> 每周事件 / Flag 阶段复盘 / 期中反馈 -> 期末人格判定
  -> 图鉴记录 / 校园纪事记录 / 隐藏称号记录 / 黑历史报告 / 再开一局
```

运行态会记录属性、行为次数、随机变体历史、Flag 进度、习惯标签、校园墙动态、人物熟悉度、吐槽历史、事件历史、剧情历史、校园纪事、隐藏称号和图鉴进度；期末根据路线评分与报告规则生成最终人格、星级、本局名场面、最大翻车点和黑历史报告。
